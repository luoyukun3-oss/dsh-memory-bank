# DSH 记忆银行（Memory Bank）

给 Agent 用的**零依赖长期记忆系统**。核心主张一句话：**不靠助手"记得去读文件"，靠 hook 把该出现的东西自动送到模型眼前。**

## 它是什么

| 项 | 值（2026-11-09 实测） |
|---|---|
| 形态 | 纯 Node 标准库，**零外部依赖** |
| 体量 | `bank/` **120 个模块 / 19381 行** + `tools/` 4439 行 |
| 命令 | `bank/cli.mjs` **31 个子命令** |
| 测试 | **38 个测试文件 / 719 条断言**全绿 |
| 隔离 | 每个仓库一套银行（`repos/<slug>/`），互不污染 |

## 自动挡怎么转的

| 时机 | hook | 做什么 |
|---|---|---|
| 会话开场 | `SessionStart` | 注入 13 段摘要（全局偏好 / 待办索引 / 近期事件 / 决策 / 故障速查 / 程序记忆 / 教训索引 …），**总预算 8000 字**、按段配额 |
| 每次提问 | `UserPromptSubmit` | 按本次提问召回相关条目 + 触发词联想（cue）；「硬约束」类条目每轮重发 |
| 调工具前 | `PreToolUse` | 按判据注入「动手前先想」的提醒 |
| 每轮之后 | 后台 | 增量摄入对话流水（限流 90 秒一次），计划任务 30 分钟兜底 |

## 能力版图

- **检索**：关键词倒排 + IDF + 软遗忘（按**召回时间**衰减，不是按索引重建时间）+ 触发词联想
- **知识页**：全局偏好 / 待办 / 事件 / 决策 / 故障速查 / 程序记忆 / 教训，分页 + 自动目录
- **事件库**：完整事件像上下文一样存，概要由模型写
- **做梦**：后台发现「未被注意的关联」，进联想收件箱**待人审**
- **LLM 抽取**：把对话喂给模型抽结构化候选，带游标 + 分批，失败可从最后成功的批复跑
- **索引治理**：结构版本自描述 / 写后自检 / 「失败率门」批量重建（超阈值不切换）
- **其它**：情绪权重（只影响语气与联想排序，**不参与事实判断**）、备份轮转、召回诊断（`cli explain`）

## 目录结构

```
_dsh_memory/
├─ bank/                  ← 记忆银行本体（120 个模块，CLI 31 个命令）
├─ tools/                 ← 周边工具（记忆星图 / 目录生成 / 图谱连边）
├─ MEMORY.md              ← 旧版记忆主干（仍保留，靠助手主动读）
├─ STATUS.md / INDEX.md   ← 旧版自动生成的状态面板与文件索引
├─ auto_memory.mjs        ← 一键刷新旧版记忆（备份 + 摘要 + 状态）
├─ digest/                ← 会话摘要（旧版）
├─ state/                 ← 工作区快照（旧版）
└─ sessions/              ← 会话日志备份（*.jsonl.zstd + manifest-*.json）
```

> 个人内容（`repos/`、`sessions/`、`digest/`、`MEMORY.md` 等）**不进仓库**，由 `.gitignore` 整体排除。
> clone 下来拿到的是**系统实现**；知识页在首次运行时自建。

## 为什么需要它

助手的"记忆"分三层，缺一不可：

| 层 | 载体 | 特点 |
|---|---|---|
| 会话内记忆 | 当前对话上下文 | 关了会话就没了 |
| 工作区指令 | `AGENTS.md`（项目根到工作目录逐级） | **每个新会话自动加载**，是"让未来的我知道该读什么"的入口 |
| **落盘记忆** | 本目录（`bank/` + 知识页） | 长期保存、可备份、跨机器可用 |

DSH 的 `dsh-agent-instructions` 插件会在每个新会话的第一次请求里注入工作区指令链，所以 `AGENTS.md` 里的提示会自动生效。

## 日常怎么用

> ⚠️ 前两条以前要**手动触发**，现在都是**自动挡**（记忆银行挂了 hook）。留删除线是为了看得出改过什么。

1. ~~**想让助手记住新的事**：对它说「更新记忆」，它会改写 `MEMORY.md`~~
   —— **不用说了**：`UserPromptSubmit` hook 每轮后台增量摄入（限流 90 秒一次），
   另有计划任务每 30 分钟兜底（hook 被沙箱拒时仍保证落盘）。你正常聊天就行，
   想更快看见就 `node bank/cli.mjs ingest` 手动催一次（幂等，不会重复记）。
2. ~~**新会话想恢复上下文**：说「先读 `MEMORY.md`」~~
   —— **也不用说了**：`SessionStart` hook 开场自动注入 13 段摘要（含待办、近期事件、决策、教训索引…）。
   想确认到底注入了什么，跑 `node bank/cli.mjs preview`。
3. **备份会话日志**：`node backup_sessions.mjs`
4. **查看某次会话的原文**：
   ```
   node read_session.mjs "sessions/<会话目录>__session.jsonl.zstd"
   ```
   （解压后是 JSONL，每行一条消息；需要 Node 22.15+ 才能内置解压）

## 想自动备份？加一个计划任务

以管理员身份打开 PowerShell，注册一个每 6 小时跑一次的任务（把 `<记忆库绝对路径>` 换成你本机的实际路径）：

```powershell
$action  = New-ScheduledTaskAction -Execute "node" -Argument "<记忆库绝对路径>\backup_sessions.mjs"
$trigger = New-ScheduledTaskTrigger -Once -At (Get-Date) -RepetitionInterval (New-TimeSpan -Hours 6)
Register-ScheduledTask -TaskName "DSH-Memory-Backup" -Action $action -Trigger $trigger -Description "备份 DSH 会话日志"
```

删除任务：`Unregister-ScheduledTask -TaskName "DSH-Memory-Backup"`

## 局限（要如实知道的）

- **注入有预算上限**：总预算 8000 字、按段配额 ⇒ 细节仍需按需 `recall` / `page`，
  **被配额截掉的那几段不会自己出现**。这是拿预算换来的确定性。
- 只有注入进上下文的那部分才算"记住了"，没进注入的只是"**可查到**"。
- 会话日志是多帧 zstd 压缩的 JSONL，能翻查原文，但不会自动变成上下文。
- `MEMORY.md` 与传统知识页写得越精炼越好 —— 太长会挤占每个会话的上下文预算（记忆银行的注入预算同理）。
